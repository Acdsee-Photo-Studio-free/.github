## 🧠 Overview

ACDSee Photo Studio is a desktop application for organizing, editing, and viewing digital photo collections. It combines a non-destructive RAW editor with cataloging tools for managing large image libraries.

On a Windows machine it runs as a desktop application with its own workspace, settings folder and uninstall entry. Typical use is photo editing and management software work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 📂 Photo Cataloging | Browses and indexes folders of images without importing or duplicating files on disk. |
| 🖼️ RAW Processing | Develops RAW camera files with non-destructive adjustments to exposure, color, and tone. |
| 🏷️ Keyword Tagging | Assigns keywords, categories, and star ratings to photos for faster searching later. |
| 🩹 Blemish Removal | Removes spots and small imperfections from images using a healing brush tool. |
| 🎨 Color Correction | Adjusts white balance, hue, saturation, and curves on individual images or batches. |
| 📊 Metadata Viewer | Displays EXIF and IPTC data such as camera settings, GPS location, and copyright. |
| 🔄 Batch Processing | Applies resizing, renaming, or format conversion to multiple photos at once. |
| 🖥️ Multi-Monitor Support | Spreads browsing, editing, and preview panes across several connected displays. |
| 📁 Duplicate Detection | Finds visually or technically identical photos across folders to help free up space. |
| 🖨️ Print Layouts | Arranges photos into contact sheets or multi-image print layouts before output. |
